# منصة التدوين والفكر والمكتبة الرقمية (مسافر عبر الزمن)

منصة تدوين ونشر فكرية ومكتبة توثيقية متكاملة، تعمل بالكامل بنظام **الملفات المحلية**.

## ما تم تصحيحه وإعادته بالكامل:
- **إعادة شريط أدوات التنسيق الغني (WYSIWYG Toolbar):**
  - أزرار الخط العريض (Bold)، المائل (Italic)، والتسطير (Underline).
  - العناوين الرئيسية والفرعية (H2, H3).
  - الاقتباس الفلسفي المائل (Blockquote ❝).
  - القوائم النقطية والمرقمة.
  - إدراج صورة داخل النص بنقرة زر.
  - إدراج الروابط التشعبية ومسح التنسيق.
- **إعادة خيارات رفع صورة غلاف المقال:**
  - رفع ملف صورة محلياً من جهازك مباشرة وحفظه تلقائياً في مجلد `uploads`.
  - أو وضع رابط خارجي مباشر لصورة الغلاف.
- **تثبيت الشعار الهندسي الفاخر، قارئ PDF بمحرك Mozilla، الوضع الليلي، والنسخ الاحتياطي.**

## التشغيل:
```bash
npm install
npm start
```
المتصفح: `http://localhost:3000`
كلمة مرور لوحة التحكم: `admin123`
